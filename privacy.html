النص الكامل للسياسة (بالإنجليزي)

In short: your shop's data stays on your own computer. If you turn on backups, copies go to your own Google Drive, and the developer has no access to them. If you use the optional multi-branch add-on, your shop's records are synced through a server only so that your tills and branches share the same data.

1.Who we are and what this covers

Z Shop (also called Shop Management) is a Windows desktop point-of-sale and inventory application made by Smart Zone. This policy explains what the application accesses, where that data is kept, and what Smart Zone can and cannot see. A separate policy covers Z Gym.

2.Data the application stores

All shop data — products, sales, receipts, stock movements, suppliers, customers and their balances, expenses and user accounts — is stored in a database file on the computer where the application is installed, under the Windows user's local application data folder. User PINs are stored as hashes, not as readable text.

Unless you use the multi-branch add-on described in section 6, this data never leaves your computer except as backups you choose to make.

3.Google Drive backup (optional)

Backing up to Google Drive is off by default. If you enable it and sign in, the application uses the Google Drive API under a single permission scope:

https://www.googleapis.com/auth/drive.file

This scope grants access only to files the application itself creates. The application cannot see, read, list or modify any other file in your Google Drive — not your documents, photos, or anything created by other applications.

What is uploaded
A copy of your shop's own database file
Where it goes
A folder named “Shop Management Backups” in your own Google Drive
Whose storage is used
Yours — it counts against your Google account's quota
Who can read it
Only you. Smart Zone has no access
Retention
You choose how many copies to keep; older ones are deleted automatically

Z Shop's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data from your Google account is used only to store and restore your backups, is never transferred to Smart Zone or anyone else, and is never used for advertising.

4.Your Google sign-in

When you link a Google account, Google issues the application an access token. That token is stored only on your computer, encrypted using the Windows Data Protection API and tied to your Windows user account. It is not transmitted anywhere else, and a copy of the file taken to another machine cannot be decrypted.

The application reads your account's email address solely to display which account is linked in its settings screen. It is not stored remotely or shared.

5.Network connections

The application makes outbound network requests only in these situations:

  • Google Drive — only when you have enabled backups and linked an account, to upload or download your backup files.
  • Update checks — the application queries the public GitHub releases API to see whether a newer version exists. This request contains no shop data. As with any web request, GitHub sees the originating IP address.
  • Branch sync — only if your shop uses the multi-branch add-on and a till has been connected to a sync server (section 6).

Printers and barcode scanners are reached through Windows on your own computer or local network. There are no other outbound connections.

6.Multi-till and multi-branch sync (optional add-on)

A shop with several tills or branches can subscribe to the sync add-on. It is never active unless a till is connected with a branch key issued for that shop.

When it is active, the till sends the shop's records — products, stock and stock transfers, sales, customers and balances, suppliers, expenses and user accounts (with PINs hashed) — over an encrypted HTTPS connection to the shop's sync server, and receives the other branches' records back. The server is operated by Smart Zone on a cloud host, or runs on the shop's own machine if the shop chooses that setup.

This data is used only to keep the shop's tills and branches in sync and to restore a till from the server. Smart Zone accesses it only to operate the service or when the shop asks for support, never sells or shares it, and never uses it for advertising. A shop can ask Smart Zone to delete its data from the server at any time.

7.Analytics and tracking

None. The application contains no analytics, telemetry, advertising, tracking or crash-reporting services. No usage information is collected or transmitted.

8.Data sharing

Smart Zone does not sell or share user data with anyone, for any purpose, including advertising, training machine-learning models, or sale to third parties.

When you use Google Drive backup, your use of Google's services is governed by Google's Privacy Policy.

9.Your control

  • Disconnect at any time — the settings screen unlinks the Google account and removes the stored token from your computer.
  • Revoke access from Google — visit your Google account permissions and remove Shop Management.
  • Delete your backups — they are ordinary files in your own Drive. Delete them as you would any other file.
  • Leave the branches — the settings screen disconnects a till from the sync server, keeping or clearing its local data.
  • Delete local data — deleting the application and its folder in your local application data removes the database.

10.Children

Z Shop is business software intended for shop owners and their staff. It is not directed at children.
